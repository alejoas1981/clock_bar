# Changelog

All notable changes to the Terminal Clock extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release of Terminal Clock extension
- Display current time in VS Code status bar (left side)
- Terminal-style time format (HH:MM:SS)
- Auto-update every second
- Clock icon with time display
- Unit tests using Mocha and Chai
- Functional tests using Playwright
- Full JSDoc documentation for all methods
- Clean Code compliant implementation
- Webpack build configuration
- TypeScript support

## [1.0.0] - 2024-01-01

### Added
- Initial stable release
- Status bar clock display
- Left-side alignment with priority 100
- Tooltip showing "Current time"
- Proper cleanup on deactivation
